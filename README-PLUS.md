# UTvTU

UTvTU（此前名为 OpenUTAU Plus）是基于 [OpenUTAU](https://github.com/openutau/OpenUtau) 的人声制作工作站，当前面向 Windows x64。

完整项目介绍、安装方法、功能范围和开发说明见 [README.md](README.md)，英文说明见 [README-en.md](README-en.md)。此文件保留为旧文档入口。

当前开发覆盖歌声编辑与合成、DAW 混音台、内置与 VST3 效果器、离线混音 / 分轨交付，以及自有 Material Design 3 主题和主窗口工具整合。

开发分支为 `plus-develop`，构建需要 .NET SDK 9。交接状态和验证记录见 [HANDOVER.md](HANDOVER.md)，协作约定见 [AGENTS.md](AGENTS.md)。

项目基于 OpenUTAU，使用 MIT 许可证，详见 [LICENSE.txt](LICENSE.txt)。
