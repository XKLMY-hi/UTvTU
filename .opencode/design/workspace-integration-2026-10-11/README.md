# 工作区整合视觉规格

`index.html` 是布局、令牌和 SVG 几何的权威；PNG 来自此 HTML 的无头渲染，**不是产品截图**。四个页面通过顶栏切换，深浅色可切，资源搜索、模式摘要及短输入的焦点回归可操作。音源名称、路径和进度均为明确标注的设计示例，没有合成、插件加载、安装或工程写入。

## 资源令牌

CSS 的示例深浅色延续此前 MD3 DAW 设计；**产品必须读取当前动态角色资源**，不能把 HTML 固定色覆盖用户主题。

| CSS | Avalonia 动态资源 | 用途 |
|---|---|---|
| `--surface` / `--surface-lowest` | `md3.surface` / `md3.surface-container-lowest` | 页面 / 编辑画布 |
| `--surface-low` / `--surface-container` | `md3.surface-container-low` / `md3.surface-container` | 壳、侧栏 / 摘要 |
| `--surface-high` / `--surface-highest` | `md3.surface-container-high` / `md3.surface-container-highest` | 字段、浮层 / 进度底轨 |
| `--on-surface` / `--on-surface-variant` | `md3.on-surface` / `md3.on-surface-variant` | 正文 / 说明、提示 |
| `--primary` / `--on-primary` | `md3.primary` / `md3.on-primary` | 主动作、焦点 / 主动作文字 |
| `--secondary-container` / `--on-secondary-container` | `md3.secondary-container` / `md3.on-secondary-container` | 选中行与胶囊 |
| `--outline` / `--outline-variant` | `md3.outline` / `md3.outline-variant` | 控件边框 / 分隔线 |
| `--error` / `--tertiary` | `md3.error` / `md3.tertiary` | 非法输入 / 编辑播放头 |

悬停状态层8%，按下12%，禁用整体38%；焦点使用2像素外环，生产可沿用已有1 DIP内描边，不改变测量尺寸。文本颜色显式转发到模板标签。短浮层用高层级实色，避免模糊编辑画布或多层卡片嵌套。

HTML 的 `symbol` 保留 `Assets/Icons.axaml` 的原生填充路径，`viewBox="0 0 256 256"`；没有描边转填充。品牌直接引用原 `utvtu-icon-32.png`，不另画品牌。新增产品图标继续用 DawIcon 按真实路径边界居中。

## 状态与输入约定

- 渲染方式默认离线，兼容方式需手动选择，摘要显示实际方式。忙时锁设置，开始禁用，取消保持可达；成功后开放输出目录。演示进度不生成文件。
- 资源选择更新详情，应用/删除/配置必须明确目标；搜索为空显示空态。右详情收起后动作放同一对象的溢出菜单。包能力未实现的动作不展示假成功。
- 底部上下文按有效选择展示，右侧基本检查器继续保留。页签切换效果、表达式、歌词和轨道设置；关闭/收起回到只见40高标题栏，重新选择页签恢复正文。无目标时说明禁用原因；动作捕获工程、片段、选择与事务身份，页面切换不把旧输入写到新目标。复杂工具沿用原入口的即时编辑或确认/取消语义，不由设计稿统一改为自动提交。
- 短浮层进入时焦点落输入，Tab循环，Esc取消、有效Enter提交，关闭恢复入口焦点。错误紧邻字段，禁止错误层再叠对话框；永久关闭宿主后迟到回调不得复活。
- 欢迎与偏好保留已认可页面。旧主题编辑器从本轮整合设计排除；主题切换仍沿用现有合法入口。

## 交付与验证

`render.cjs` 仅启动独立无头浏览器渲染本目录 HTML，不附着产品。运行：`node render.cjs`（依赖本机 bundled Playwright 与 Edge）。`validation.json` 记录浏览器版本、图像列表、800 DIP滚动/边界、模式摘要、自定义范围展开、忙时锁输入/取消恢复、资源搜索空态、底部面板全宽/43vh/40标题/调高/收起/四页切换、浮层焦点进入/恢复与页面错误。PNG 按实际渲染查看后交付；没有产品截图、产品构建或产品测试。

渲染深/浅色全页图为1440×1080，可看到完整摘要；资源/上下文/短浮层为1440×900；窄窗图为800×650。`context-dark-1440.png` 已替换为全宽底部效果面板，另附 expressions/lyrics/track 三页PNG。常见900高窗口的渲染设置允许滚动，摘要并不强求所有高度下同时可见，作业按钮始终固定。全部交互检查通过、页面错误为0。图像不是插件听觉、Avalonia字体光栅化或产品布局验收证据。

设计不新增生产架构或能力。实际迁移与验证由主 agent 负责，提交记录不表示全部产品已按示例实现。
