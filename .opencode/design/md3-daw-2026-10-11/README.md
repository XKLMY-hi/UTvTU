# UTvTU · 紧凑 MD3 人声工作站设计

2026-10-11。面向现有 UTvTU 的视觉与交互重构提案，Windows 为目标平台。
本目录是独立设计原型，没有修改 Avalonia 应用；页面的保存、试听、合成和导出均不操作用户工程或音频。

## 设计取舍

MD3 的色彩角色、状态层、清晰分区与聚焦反馈用于组织桌面工作区。密度按鼠标、键盘和持续编辑适配，
不是移动端组件尺寸的逐像素复制。主窗口不嵌套大圆角卡片；边界使用 1px 分隔线，圆角用于可交互对象。

官方依据：[色彩角色](https://m3.material.io/styles/color/the-color-system)、
[文字角色](https://m3.material.io/styles/typography/applying-type)、
[多窗格布局](https://m3.material.io/foundations/layout/canonical-examples/overview)。
以下尺寸与数值是本设计的具体决定，不声称是 MD3 标准的固定默认值。

- 播放、时间、节奏、循环、节拍器常驻。仅播放和导出使用明显强调。
- 三个工作视图由同一导航条组织，保留工程上下文、选中轨道、混音值和编辑状态。
- 左侧检查器只显示当前对象的参数；右侧在编排/歌声编辑显示素材，在混音显示所选通道效果链。
- 时间线、音符、波形、电平是视觉中心。曲线、轨道色与选中状态不依赖浮层玻璃或大面积渐变。
- 混音台的主输出固定在右侧。轨道通道横向滚动；电平和数字始终保留。
- 专业内容使用有单位的数值、等宽时间、音高/歌词、格线和信号顺序；小字号仅用于辅助信息。

当前实现值得保留的分离宿主、面板折叠、轨道色、声库/素材分类以及 MD3 资源角色都可继续使用。
提案没有引入总线、自动化轨道、录音或新合成器等未确认的产品能力。

## 信息架构与行为

| 区域 | 编排 | 歌声编辑 | 混音 |
|---|---|---|---|
| 顶层导航 | 编排选中 | 歌声编辑选中 | 混音选中 |
| 左检查器 | 当前轨道、声库、混音、所选片段 | 当前片段、音符歌词/音高/长度、表情 | 当前轨道、声库、混音、输出路由 |
| 中央工作面 | 轨道头、节拍时间线、歌声片段/伴奏 | 键盘、节拍、歌词音符/音高、表情 | 通道、插入效果摘要、声像、M/S、推子/电平 |
| 右支持面板 | 声库/音频/MIDI/效果 | 同编排 | 所选通道的效果链 |

原型可实际操作：

- 点击视图、Ctrl+1/2/3、导航标签左右方向键；双击歌声片段进入歌声编辑。
- 点击轨道或通道、更换当前检查器；选择音符；素材搜索、类型切换；表情标签切换。
- 轨道音量推子、左侧音量输入/滑块、M/S：更新原型共享状态、未保存提示与撤销/重做。
  一次推子 change 事件建立一条历史；移动过程实时预览数值，不逐帧写历史。
- Ctrl+Z / Ctrl+Y、保存按钮 / Ctrl+S；保存仅记录内存快照，刷新页面重置演示。
- 检查器/素材面板折叠、主题切换、播放/停止/循环/节拍器的状态示意；Space 在编辑器外切换播放。
- 导出对话框与取消；合成任务状态示意。菜单、分离、导入、插件入口以提示展示。

未实现音符绘制/拖动、歌词真实编辑、网格吸附、时间线缩放滚动、FX 参数/排序、实际插件 GUI、文件 IO 或音频。
主输出推子只展示、不接收修改；电平、波形和合成状态均是示例。
截图中的声库和素材名称是示例名称，不附带这些资源。

### 落地时必须明确的状态

- **无可编辑片段**：歌声编辑入口使用明确禁用和说明，或打开当前选中歌声片段；不得点击后静默返回。
  原型预置可编辑片段，未覆盖空工程状态。
- **未保存 / 保存失败**：修改与保存按工程修订比较；不能只因为窗口关闭才补标脏。
  保存失败保留修改和恢复路径，成功提示必须对应实际文件写入结果。
- **合成中 / 过期 / 失败**：合成状态绑定工程和片段修订；过期结果不显示为最新。
  本原型只示范任务状态位置，不能作为合成实现依据。
- **效果编辑**：推荐直接实时编辑，修改即成为可撤销工程操作。效果窗口关闭不做隐式回滚。
  如未来保留可取消预览，必须同时规定保存/导出/切换的提交策略。
- **切换工程**：关闭或解绑旧会话的检查器、效果、任务与分离视图；旧回调不得污染新工程。

## 几何、令牌与 Avalonia 映射

所有单位为 CSS 逻辑 px；迁移时对应 Avalonia DIP。不要把整页 PNG 当作背景贴图。

| 几何/样式 | 设计值 | Avalonia 落地建议 |
|---|---|---|
| 标题装饰示意 | 32 高 | 保留原生 Windows 装饰，原型中的标题行不要求自绘 |
| 菜单 / Transport / 工作视图栏 | 30 / 60 / 40 高 | 三个明确职责的行；布局资源不与控件皮肤混杂 |
| 模块工具行 / 状态栏 | 40 / 25 高 | 文本和按钮显式继承/绑定模板属性 |
| 左检查器 / 右支持面板 | 220 / 256 宽 | Grid + 现有面板分隔器；宽度持久化，中心优先 |
| ≤1200 宽 | 左 200 / 右 232 | 当前桌面布局的紧凑断点 |
| ≤1050 宽 | 右侧默认收起，可临时覆盖展开 | 保留常驻重新展开按钮；覆盖层需焦点管理和 Escape 返回 |
| 普通按钮 / 主要播放 | 32 高 / 40×40 | 桌面密度；不要继承全局 Margin 后意外增高 |
| 控件 / 片段 / FX 折叠容器圆角 | 6 / 4 / 6 | Pane 本身 0；顶层不做卡片嵌套 |
| Track lane / 通道 / 固定主输出 | 90 高 / 116 宽 / 124 宽 | 编排轨道高度和混音通道宽可进一步接现有缩放能力 |
| 编排轨道头 / 卷帘键盘 | 148 / 48 宽 | 节拍线、键盘、音符/表情横向坐标必须一致 |
| 音符半音行 / 表情面板 | 22 / 128 高 | 前端绘制坐标由专用编辑模型提供 |
| 默认正文 / 轨道/工具文字 / 辅助 | 12 / 11 / 9–10 | 正文 Segoe UI + 微软雅黑 UI；时间/数值 Cascadia Mono + Consolas |
| 时间主读数 / 轨道检查器标题 | 18 / 14 | 等宽时间，显式文字样式，避免全局 TextBlock 覆盖 |
| Hover / Pressed 状态层 | 8% / 12% | 基于 on-surface；选中用 secondary-container 和 primary 线条；16% 为覆盖层预留值 |
| 键盘焦点 | 2px，外偏移 2px | :focus-visible 对应键盘焦点伪类，不能全局关 Button 聚焦 |

颜色真值位于 `index.html` 的 `:root` 和 `[data-theme="light"]`；以下列常用角色：

|---|---|---|
| surface / surface-lowest | #141318 / #100F14 | #FAF8FD / #FFFFFF |
| surface-low / container / high | #1C1B21 / #222128 / #2B2932 | #F2EFF7 / #ECE8F2 / #E5E0ED |
| on-surface / on-surface-variant | #E8E1ED / #C8C0D3 | #1D1A23 / #4B4558 |
| primary / on-primary | #C6BAFF / #302065 | #5C4694 / #FFFFFF |
| primary-container / on-primary-container | #45327C / #E9DDFF | #E9DDFF / #27124F |
| outline / outline-variant | #958D9F / #45404E | #7B7288 / #CDC5D8 |
| tertiary / warning / error | #91D5C4 / #E6C578 / #FFB4AB | #176B57 / #7A5A15 / #B3261E |

轨道五色与网格/电平另有专用令牌。轨道色是身份提示，不等价于按钮 primary；电平色不复用错误色。
图标在 HTML 的 `<symbol viewBox="0 0 24 24">` 中定义；绝大多数为 1.7px 圆角描边。
自绘编辑层继续使用原生路径/线条，主题令牌应传入画布，不能在业务代码硬编码截图颜色。

### 品牌原生源

品牌 Mark 来源于 `../brand/extracted/mark.svg`。
本稿逐字保留 viewBox `0 0 64 64`、完整路径 d、fill=none、stroke-width=10、Round cap/join、
non-scaling-stroke；源 80×80 元素整体用 CSS `scale(.3)` 显示为 24×24。
仅颜色映射到主题 primary，没有从 PNG 描摹、偏移或把描边改成填充。Wordmark 与括号未使用也未改造。

## 键盘与可访问性

图标按钮有中文可访问名称。切换动作声明 `aria-pressed`，标签声明 `aria-selected`、关联面板与 roving Tab。
键盘焦点有可见轮廓；当前音符、轨道、静音状态同时通过文字/形状表达。
主题不改变动作位置。深浅截图已查看，但没有声称完成整套 WCAG、屏幕阅读器或高对比度验证。

落地时补齐：编辑器内 Tab/方向键/Space 规则、歌词输入焦点、不活动视图的焦点恢复、分离回收焦点、
面板分隔条键盘替代动作、系统高对比度、100%/125%/150% 缩放。轨道头小目标是桌面密度选择，
应保留至少 24px 命中区，并为触摸/辅助输入提供更大密度选项。

## 渲染与验证

使用本机 Edge headless + Playwright 渲染本目录 HTML，**没有抓取现有 UTvTU 应用截图**。
每轮看新设计的 PNG；已修正默认 SVG 300×150、窄窗 1px 溢出、推子刻度/值不一致、
键盘音高/所选属性不一致、播放/暂停图标状态，以及窄窗素材面板可重新打开的问题。

[validation.json](validation.json) 记录渲染时间、浏览器版本、图像列表和交互断言。
当前验证：7 张图；1440×900 深浅三视图与 1024×768 卷帘；页面脚本错误 0；窄窗文档宽等于视口宽；
M/S 未保存/撤销/重做、轨道音量从 −3.2 改到 −10.1 后撤销、原型保存、双面板折叠、Ctrl+2、
主题切换、导出对话框和窄窗右面板重新展开均通过。

复现：`node render.cjs`。脚本默认使用本机 bundled Playwright 和 Edge；可用
`UTVTU_DESIGN_NODE_MODULES` / `UTVTU_DESIGN_BROWSER` 指定安装路径。
产品构建/测试、真实音频一致性、实机 DPI 与 Avalonia 模板行为不在本设计原型验证范围内。

## 迁移建议

先与混音编辑事务一起迁移通道与检查器：共享音量/M/S 操作、保存提示、撤销与效果编辑契约，
同时换成这里的紧凑几何和角色色。其后迁移常驻 Transport/导航，再接歌声编辑器。
每个模块落地均以可操作工作流验收；保留现有功能入口、快捷键、分离保护和画布命中逻辑。
不把整个 HTML 逐元素映射成一个巨型 MainWindow，也不新增第二套主题框架。
