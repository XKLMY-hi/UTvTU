# 轨头（归道）档位表 —— W45/S1′ 可执行规格

> 来源：**m3-chain** 为 W45/S1′ 算出的档位账（他的原话见团队消息；本文件是他的算术的落档版）。
> 用途：**执行者照此落地，不必重新侦察**；Lead 的两条裁决也记在下面。
> 设计依据：`.opencode/plans/trackheader-design.md` §4–§6。

## 0. 两条 Lead 裁决（2026-10）

1. **42 档裁掉音量行**（63+ 恢复）——内框高 28、主行占 24，再塞音量行 16 ⇒ **40 > 28 ✗**；
   "42 档保留滑杆"的本意只是"**别塞 dB 数字**"，顺带变成"不塞整行"可接受。音量/声像在 42 档经 ⚙ 与右键可达。
2. **窄列动作条换到第二行**（**仍是横排图标行**，符合用户"图标横向并排"的诉求）——
   正常档 206 + 头像 44 + 6 = **256** ⇒ 需列宽 ≥ **274**，而**我们默认列宽是 248**（W16 定的，非设计稿 268）
   ⇒ 默认档根本用不了"同行"档；硬压到 22×20 + badge 30 时**名称只剩 6px** ✗ 不可用。
3. （护栏断言）**默认列宽 248 下名称 `Bounds.Width ≥ 100`** —— 专门拦"以后又把动作条硬压回同行"。

## 1. 账目口径

- 卡片 = 轨道高 − 4（外边距）− 2（描边）
- **内框宽 = 列宽 − 18**（内边距 6,4,6,4 的横向 + 描边）
- **内框高 = 轨高 − 14**（4 外边距 + 2 描边 + 8 纵向内边距）

## 2. 高度档（内框高 = 轨高 − 14）

| 轨高 | 内框高 | 内容 | 校验 |
|---|---|---|---|
| **42** | **28** | 主行 24（名称 18 与动作条同行）｜**无音量行、无 chips** | 24 ≤ 28 ✓（+16 ⇒ 40 ✗） |
| **63** | **49** | 主行 24 + **音量行 16** = 40｜**无 chips** | 40 ≤ 49 ✓（+chips 16 ⇒ 56 ✗） |
| **84** | **70** | 主行 + 歌手 chip + 音量 = 56（**音素器 chip 从 84 档起**） | 56 ≤ 70 ✓ |
| **147** | **133** | 全量（歌手 + 音素器 + 渲染器 + 音量/声像） | ✓ |

## 3. 宽度档（内框宽 = 列宽 − 18）

| 列宽 | 动作条 | 账 |
|---|---|---|
| **≥ 274** | **206** 与名称同行：26×4（M/S/fx/⚙）+ badge 86 + 间距 16 | 206 + 头像 44 + 间隙 6 = 256 ≤ 274−18=256 ✓ |
| **200–273** | **174 换第二行**：22×20×4 + badge 74 + 间距 12 | 248 默认列下名称 = 230 − 44 − 6 = **180 ✓ ≥100** |
| **42 高（任意宽）** | **必须同行**，用**瘦组 82**：M/S/fx 18×18 + badge 仅状态点 20 + 间距 4×3 | 248 下名称 = 230 − 24 − 6 − 82 = **118 ✓**；200 列下仅 70（**已知最紧档**，报告里登记） |

⚠ **由此 42 档的 ⚙ 必须挪进卡片右键菜单**（否则 5 件套最少 113 ⇒ 名称 87 < 100 ✗）：
菜单项「轨道设置」**复用** `TrackSettingsButtonClicked`（入口已由 fx-ctl 补上，`ff02213d`）；**引擎 badge 恒常驻**（W33 硬要求，任何档位不得消失）。

## 4. 断言（`EveryChild_StaysInsideTheCard` **一行不改**，只新增）

1. 248 默认列 × 四档：名称 `Bounds.Width ≥ 100`；
2. 42 档 `LevelsRow.IsVisible == false`、63+ 为 true；
3. 200–273 列：动作条 `Bounds.Y` 在名称行底之下且与名称**不重叠**；
4. 四档 × 三宽度：M/S/FX/⚙/badge 的 `Bounds.Height ≥ 18`，且 **badge 恒可见**。
