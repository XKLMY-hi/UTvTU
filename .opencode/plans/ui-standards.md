# UTvTU UI 设计标准（v1，2026-10）

> 适用：所有 `Views/**`、`Controls/**`、`Styles/**`、`ViewModels/**` 的改动。**违反者不予合并**（部分条目由 `.dsh/fx/ui-lint.ps1` 自动检查）。
> 本文只写**可判定**的规则；每条都给出"为什么"与"怎么验"。历史踩坑出处见 `.opencode/plans/mixer-rebuild.md` 附A/附C。

## 0. 三条不可协商的前提

1. **一切以 `md3.*` 令牌取色与取尺寸**：颜色只能来自 `DynamicResource md3.*`（画刷）或 `md3.color.*`（Color）；surface 有 **5 档**（含 `surface-container-lowest`）。**禁止硬编码色值**（lint 会拦）。
2. **禁止新增应用级 `/template/` 补丁**：应用级补丁会压过控件自身的 `ControlTheme`，产生"改了没效果/别处崩样式"的连锁。控件要改模板，就在**该控件自己的 `<UserControl.Styles>`** 里补（历史上已清过 9 条，勿再加）。
3. **UI 线程亲和**：任何会改**绑定集合 / StyledProperty / 视觉树**的订阅者与命令回调，必须过 `UiThreadAffinity`（锚定"所属线程" + `Post`）。**不用 `Dispatcher.UIThread.CheckAccess()`**（headless 会误判、已踩两次）、**不用 `Invoke`**（与 `DocManager` 锁互锁）。这条同类缺陷已复发 **4 次**。

## 1. 尺寸与控件

| 项 | 规则 |
|---|---|
| 间距/内边距阶梯 | 4 / 6 / 8 / 10 / 12 / 16（禁止 5、7、9、11 这类"看着调"的值） |
| 圆角 | 控件 4 · 卡片 8 · 面板/对话框 12 · 胶囊 999 |
| 字号 | 10（状态条/读数）· 11（面板标题、胶囊）· 12（正文/列表）· 13（对话框标题）；字重只用 Regular / SemiBold |
| **控件高度下限** | 全局 `Md3ButtonTheme` 有 `MinHeight=32` 与应用级 `Button{Margin:0,4}` ⇒ **任何声明 <32 高的 Button 类必须在自己样式里同时压 `MinHeight` 与 `Margin=0`**，否则渲染成 32 高、行高被撑 8px（M/S 曾 20→32、链行 ✕ 22→32） |
| 命中区 | **命中区 ≥ 视觉尺寸**：细线 1px ⇒ 命中 7px；14px 行 ⇒ 命中 22px |
| 类型选择器 | Avalonia 类型选择器是**精确匹配**：`Button` 样式**不影响** `ToggleButton`；写"通用按钮"样式时要确认目标实际控件类型 |

## 2. 布局与面板（`PanelSplitter` 契约）

1. **五值必填**：`PanelColumn`（或 `PanelRow`，排除自身列/行）、`Min`、`Max`、`DefaultWidth`、`CenterMin`（中央区**净**尺寸，分隔条自身 7px 恒占位）。
2. **意图值/有效值分离**：`Target` = 用户意图（**夹紧不得改写**，供持久化）；容器只绑 `PanelWidth`/`PanelShown`（或行方向的 `PanelHeight`）。
3. **保留尺寸按列/行序升序计算**（左/上面板用当前有效值、右/下面板只用 Min）——否则两面板互相按当前值夹紧会两态振荡，Avalonia 直接报 `Infinite layout loop detected`。
4. **放不下时**：允许跌破 `Min`（夹到 `max(0, 可用 − 保留 − CenterMin)`）；低于 **120px（列）/ 80px（行）** 自动折叠，**不留夹缝、不留残留 1px 线**。
5. **折叠入口必须始终可达**：面板 chevron + 顶栏「布局」+ 工具菜单 + 「重置面板布局」，缺一不可（折叠后找不回来是 P0 级体验缺陷）。
6. **持久化只走 `Preferences.Default.PanelLayout`**（唯一存储，禁止平行字段）。
7. **窗口下限**：主窗 ≥800、分离窗 ≥640（低于此任何布局都无意义）。
8. **切换/折叠不得引起布局抖动**：过渡只做"不参与布局"的淡入；不给宽度/高度做动画。

## 3. 交互

1. **键盘可达**：每个鼠标操作要有等价键盘路径（新面板至少给折叠/复位快捷键或在工具菜单里可达）。
2. **双击复位**：分隔条、可拖动数值一律支持双击回默认。
3. **可撤销**：任何改变工程数据的操作走 `DocManager.ExecuteCmd`；**视图态**（选中、展开、滚动、视口）**不进撤销栈**。
4. **动效服从 `ReduceMotion`**：滚动/缩放/弹层动画都要在 `Preferences.Default.ReduceMotion == true` 时**立即到位**。
5. **状态可见**：开关类控件必须有当前态反馈；"点了没反应"必须给出原因（如"按 I 显示弯音后可编辑音高节点"）。

## 4. 渲染与性能预算（"动态取舍"的判据）

**硬预算（超了就不合）**

| 预算 | 阈值 | 现状基线（实测） |
|---|---|---|
| 音频线程分配 | **必须 0 B/块** | VST 处理曾 2072 B/块 → 修后 0（16 轨约 2.8 MiB/s 垃圾） |
| 每帧重绘范围 | 只重绘**内容变化的最小区域**；不做全画布重绘 | 波形 25 帧重混 25→5；卷帘每帧部件重绘 3→1 |
| 同帧共享可变绘制对象 | **禁止**：`Geometry`/`Points`/`Pen` 等保留模式对象不得被同一 pass 的多处改写 | 音高线/颤音线/最终音高线共用 `polylineGeometry` ⇒ 互相顶替（已修） |
| 每次打开/切换视图 | 不阻塞 UI 线程；>100ms 的工作必须异步 + 可取消 | 插件首扫约 16s，后台 + "正在扫描…"提示 |

**"花性能换功能"四问**（全部通过才允许默认开；任一不过 ⇒ 默认关或降级，并给开关）
1. 这段代码在**音频线程**上吗？（是 ⇒ 零分配、零锁、零 IO，否则一律不可）
2. 它**每帧**跑吗？（是 ⇒ 预算按帧算，且必须能增量/脏区）
3. 成本随**内容规模**线性放大吗？（是 ⇒ 必须缓存/惰性/分页，或给上限）
4. 它**能证明收益**吗？（不能测 ⇒ 先做**可关的实验开关**，附测量方法，别直接默认开）

**测量义务**：任何以性能为理由（或代价）的改动，提交里必须附**前后数字**（分配/重绘次数/耗时/帧时任一），并说明测量方法与口径。**没有数字 = 没有说服力**，评审直接退回。
**回退开关**：可能影响低端机体验的功能必须可关（`ReduceMotion` 是范例）；开关默认值要写理由。

## 5. 可测性（本仓特有约束）

1. **headless 的绘制是桩，但布局是真跑的** ⇒ 几何一律断言**布局后的 `Bounds`**，不要断言属性（"属性绿、像素红"已骗过我们两轮：M/S 20 vs 32）。
2. **隐藏元素的 `Bounds` 会保留上次排布值** ⇒ 折叠类断言改看有效尺寸属性与邻居占位。
3. **真实像素**由验证者用 computer use 量（合成输入触发不了 `:pointerover`，伪类注入对"祖先条件选择器"无效）⇒ 需要 hover/active 证据时，写"仅代码审查 + 交验证者真机"。
4. **不写像素断言**（headless 桩绘制）；不依赖网络/用户机器上的音源或插件。
5. **测试不留全局态**：`DocManager` 线程态 / `SingerManager` / VST 单例 / `MessageBus` 订阅 / 语言 / `Preferences` —— 作用域化 + 用后恢复（已有 `EnterScopedDispatcher`、`ScopedSingers`、`WithVstGlobal` 三个现成工具）。

## 6. 提交前自检（评审用）

```
[ ] 只动 md3.* 令牌？无硬编码色？无新增应用级 /template/ 补丁？
[ ] 声明 <32 的 Button 都压了 MinHeight + Margin？ToggleButton 没被 Button 样式误伤？
[ ] 新面板走了 PanelSplitter 五值 + 意图/有效值分离 + 升序保留 + 折叠可达 + 单一持久化？
[ ] 改绑定集合/StyledProperty 的路径都过 UiThreadAffinity？
[ ] 渲染：只重绘变化区？无同帧共享可变绘制对象？
[ ] 性能或代价有前后数字？影响低端机的功能有开关？
[ ] 几何断言用 Bounds？测试无全局态残留？
[ ] 命令走 ExecuteCmd？视图态不进撤销栈？ReduceMotion 生效？
```

## 7. 自动检查

`pwsh -File .dsh\fx\ui-lint.ps1`（在仓库根运行）：硬编码色值、应用级 `/template/` 补丁、UI 代码里的 `CheckAccess()`/`Invoke`、共享可变绘制对象的可疑模式、`PanelSplitter` 五值缺失、声明 <32 高的 Button 未压 MinHeight。**并入前跑一次**（和 `checks.ps1` 一起）。
